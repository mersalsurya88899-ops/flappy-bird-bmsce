# Flappy Bird BMSCE Edition 🎮

A custom Flappy Bird clone built using HTML5 Canvas and JavaScript.

## ✨ Features
- Gravity flip every 15 pipes 🔄
- Dash ability (Shift key) ⚡
- Coin collection with separate counter 🪙
- Day/Night mode 🌗
- BMSCE themed pipes 🏫
- Screen shake on crash 💥

## 🎮 Controls
- Space → Flap
- Shift → Dash forward
